# Jarvis-Pro (Prototype)

This folder contains a self-contained prototype for a Jarvis-like assistant with a web chat UI.

## What it includes
- `frontend`: a simple browser UI
- `backend`: an Express server that serves the UI and exposes a `/api/chat` endpoint
- `agent`: a command router that can be extended to your PC control + browser automation modules

## Next steps
1. Install dependencies in `Jarvis-Pro/backend`
2. Run the backend
3. Open the UI

(These steps can be updated once we can integrate your existing Python automation modules.)
